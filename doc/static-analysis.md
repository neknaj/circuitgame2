# 定常化と周期の静的解析

## 自動解析

解析対象は型・結線検査と階層展開を終えた参照ネットリストとする。未使用ゲートの削除など、内部状態を変える最適化の前に解析する。公開出力の trace が同じでも、未使用の発振器を削除すると回路全体の周期が変わり得る。ソースに注釈がなくても、[エディタのインレイヒント](development.md#推論結果のインレイヒント)や解析コマンドで定常化の上界と周期を確認できる。結果は、ルート文書と参照先のファイル・マクロ・設定を含む解析スナップショットに対応させる。状態の範囲、固定入力、tick の数え方は[シミュレーション仕様](simulation.md#定常状態と周期定常状態)で定義する。

初版は階層を展開したゲート専用の非循環回路を対象とする。入力ポートと定数の深さは0とする。別名、スライス、連接、フィールド参照、表現変換は各ビットの元の深さを引き継ぐ。各ゲートの深さは入力信号の最大深さに1を加えて求める。深さ1のゲートは1 tick 後に固定入力だけで決まる。深さ $`d`$ のゲートは、深さ $`d-1`$ 以下の入力が確定した次の tick に確定する。この帰納法をすべての内部ゲートに適用し、最大深さを定常化の上界として求める。例えば2個の NOR を別名の配線を経由して直列につないだ回路の上界は2 tick である。

フィードバックを含む回路では、候補の tick 数と周期を探索する方法を追加できる。例えば小さい回路なら、固定入力ごとの状態遷移をたどり、軌道が繰り返し始めるまでの長さと周期を数えられる。すべての対象状態・固定入力に共通する結果を検証できたときに表示する。解析できる範囲を超えた場合は、保証が得られたとは表示しない。

## 指定した条件の検査

自動推定は初版に含める。明示した条件は、初版では解析コマンドから `--within N`（経過 tick の上界）と `--period p`（繰り返しの間隔、省略時は1）を受け取る。検査対象は[実行設定](project-config.md)で選んだルート、またはコマンドで選んだモジュールとする。CI は指定した条件の検証済み、反例あり、未証明を区別できる終了状態を受け取る。テストへの組み込みと任意の[ソース注釈](circuit-language.md#定常化と周期の注釈)は拡張候補とする。

ゲートの深さから得た上界が指定値以内なら、指定した任意の正の間隔について条件を検証できる。上界の時点で不動点に達し、そこから各 tick で同じ状態を保つためである。上界が指定値を超え、他の検査結果がなければ未証明を返す。周期の条件を直接検査する拡張では、型で許される状態と固定入力を変数にし、$`N+p`$ tick まで参照遷移を展開する。$`s_{N+p}\ne s_N`$ を満たす割り当てがあれば反例となる。外部ソルバーを用いる場合の証明前提は[検証設計](verification.md#仕様との対応)を参照する。

| 表示 | 自動解析 | 指定した条件の検査 |
| --- | --- | --- |
| 検証済み | 例「固定入力で2 tick以内に定常化。ゲート深さによる上界」 | 宣言した上界と周期について成立を確認した |
| 反例あり | 対象となる要求が指定されていないため表示しない | 初期状態、固定入力、不一致の tick と値を示す |
| 未推定／未証明 | 自動では保証を得られなかった。通常の診断には出さない | 検査方法の対象外や探索未完了など、証明できなかった理由を示す |

注釈の有無と解析結果は回路の実行規則に影響しない。
