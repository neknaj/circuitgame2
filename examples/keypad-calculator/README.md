# キー行列と I²C LCD の電卓

4×4 のキー行列を読み取り、0〜99 の整数を加減算し、4 桁の 7 セグメント LCD に結果を表示する例。計算は NCG2 の `::add-subtract` が行い、加算器は lib の XOR、AND、OR を使う。

このディレクトリで [lib の取得手順](../README.md#使い方)を実行し、Python 3 で試す。

```sh
python demo.py "19+23="
python demo.py "3-12="
```

1 行目にキー入力と LCD から読み取った表示、2 行目に I²C で送ったバイト列を表示する。この例の結果は `42` と `-9` になる。キー `C` はそれまでに読み取った入力を消去する。

## キー行列と LCD のモデル

NCG2M で実装するモデルのポートと tick は [I²C 接続の7セグメント LCD](../../doc/peripherals/i2c-pcf8576d.md)に定める。この例の Python は各クロック位相の代表点を並べ、書き込むバイトとセグメントの対応を確かめる。実行時の tick 列は NCG2M モデルの実装後に検査する。

```text
1 2 3 +
4 5 6 -
7 8 9 =
C 0 · ·
```

スクリプトは一度に一つのスイッチが閉じるものとして、行を順に Low にし、列からキーを読む。表示は PCF8576D の静的駆動を想定する。アドレス選択とサブアドレスを 0 とし、BP0 を共通のバックプレーンに使う。各桁の 8 本のセグメント線は、データシート図13の順で割り当てる。送信側は START、データ、STOP を生成する。9 クロック目は SDA を解放し、LCD モデルが指定したアドレスとコマンドを受け付けたときに ACK を返す。バスの論理レベルから表示データを読み取る。

キー走査、状態管理、I²C、LCD は Python で模擬する。実機の GPIO とタイミング、複数キーの同時押し、接点のチャタリングは未検証。CLI で自作デバイスとして動かすには、NCG2M で定義したデバイスを登録・実行する仕組みが必要になる。
